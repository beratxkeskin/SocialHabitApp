# Social Habit Accountability App

A social habit tracking application focused on accountability between trusted users.

## Core Idea

Users create shared habits, check in daily, see each other's progress and send lightweight nudges when somebody has not completed the habit.

## Primary Stack

### Android
- Kotlin
- Jetpack Compose
- Material 3
- MVVM
- Clean Architecture
- Hilt
- Coroutines
- Flow / StateFlow

### Backend
- Supabase PostgreSQL
- Supabase Auth
- Supabase Realtime
- Supabase Storage
- Supabase Edge Functions

### Firebase
- Firebase Cloud Messaging
- Crashlytics
- Analytics
